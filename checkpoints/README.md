# FAST checkpoint

Download `pretrained_model_gt.pth` from the GitHub Release for the version of
this repository and place it in this directory. The proposed first-release
URL is:

```text
https://github.com/ZeMA-gGmbH/FAST/releases/download/v0.1.0/pretrained_model_gt.pth
```

Expected size: `81,120,721` bytes. The public asset contains 54 model tensors
as a raw state dictionary without training metadata. The checkpoint is
intentionally excluded from Git history and must be published as a GitHub
Release asset.
